# Home Constitution

Home is a mirror, not a dashboard.

It shows what is true about the person right now — not a history, not a trend, not a forecast. It reflects the present state of their recurring commitments, filtered through the same editorial principles that govern the rest of SubWise: one idea at a time, facts over opinions, silence as a valid state.

Home never repeats what the Journal already preserves. Home speaks in the present tense. The Journal speaks in the past tense. Home has no memory beyond what is true today; the Journal is where yesterday's truths go once they stop being today's truth.
